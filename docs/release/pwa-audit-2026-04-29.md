# PWA Polish Audit — 2026-04-29

Goal: contractor on a building site / tenant in a basement still gets a useful TenureIQ shell when offline.

## Audit summary (before → after)

| Bucket | Before | Severity | After |
|---|---|---|---|
| **Manifest** | Present, but `name` short, no `scope`, no `lang`, no `id`, single combined `"any maskable"` purpose (icons get cropped on Android adaptive tiles), `background_color #0f172a` (slate-900) didn't match dark token `222 30% 8%` (#0e131f) | Medium | `name` → "Tenure IQ — Property Intelligence", added `scope:/`, `id`, `lang:en-GB`, `dir:ltr`, `display_override`, split icons into dedicated `any` and `maskable` entries, fixed `background_color` to `#0e131f` |
| **Vite PWA plugin** | Not installed; project uses a hand-written `public/sw.js` | Low (intentional) | Unchanged — kept hand-written SW (avoids preview-iframe issues per project memory + PWA guideline) |
| **Service worker** | Registered from `index.html`, **no iframe guard**, navigation-only fetch handler, no asset caching at all | High (preview iframe pollution + nothing useful cached) | v2: iframe + preview-host guard, network-first navigations w/ offline fallback, **cache-first only for hashed `/assets/*`**, network-only for Supabase + `/api/*` + `/auth/*` + `/~oauth` |
| **Offline fallback** | `offline.html` present and served on navigation failure | OK | Unchanged. API failures still surface through the app's existing error boundaries (intentional — we never serve stale user data) |
| **Icons** | `pwa-192x192.png` was actually 1024×1024 mislabeled (248 KB), `pwa-512x512.png` was a 7.5 KB low-res JPEG-in-PNG, no apple-touch-icon, no maskable variant, no 16/32 favicons | High | Regenerated proper 192/512 (correct dimensions, ~8 KB / 56 KB), added `apple-touch-icon.png` (180×180), `pwa-192x192-maskable.png`, `pwa-512x512-maskable.png` (with 80% safe zone on navy `#1e3a5f`), `favicon-16x16.png`, `favicon-32x32.png` |
| **Theme color** | Single `#1e3a5f` | Low | Now light/dark pair via `media` attribute (#1e3a5f / #0e131f) + iOS web-app meta tags |

## Caching strategy (final)

| Request | Strategy | Reason |
|---|---|---|
| Navigation (HTML) | Network-first → `/offline.html` | Always fresh; basement fallback |
| `/assets/*` (Vite hashed) | Cache-first | Filename hash makes them immutable |
| `/favicon*`, `/pwa-*`, `/apple-touch-icon`, `/manifest.json` | Cache-first | Static, infrequent change |
| `*.supabase.co/*` | Network-only (uncached) | User data — never serve stale |
| `/api/*`, `/auth/*`, `/~oauth` | Network-only (uncached) | Auth + live data |
